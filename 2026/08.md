## 🏆 Top 3 Picks

### 🥇 #1 - ShareLint
**Repo:** [`jasonzhang06-source/sharelint`](https://github.com/jasonzhang06-source/sharelint)  
**Language:** Python  
**Why it stands out:** A local check for the files people actually send: documents, images, folders, and nested archives. It looks beyond source-code secrets to hidden sheets, speaker notes, and metadata, and reports surfaces it could not fully inspect. Its gated packing workflow helps turn the scan into a repeatable sharing step. The project is alpha software with growing format coverage.

**Highlights:**

- Local scans without uploading files
- Secrets, personal information, document content, and metadata checks
- Masked findings and explicit inspection-coverage gaps
- Policy-gated ZIP creation followed by an output rescan

---

### 🥈 #2 - QymCAD
**Repo:** [`QymIs-Tech/QymCAD`](https://github.com/QymIs-Tech/QymCAD)  
**Language:** Rust  
**Why it stands out:** A desktop CAD project that combines parametric sketches, solid modeling, and assemblies in one application. OpenCASCADE provides the geometry kernel, and STEP exchange connects the results to other CAD tools. The development build documents changing project-file compatibility and an unfinished CAM module, so its promise is strongest as an actively evolving mechanical-design tool.

**Highlights:**

- Constrained sketches and parametric dimensions
- Extrude, revolve, sweep, fillet, and other solid operations
- Assemblies with joints and associative references
- STEP, STL, DXF, and SVG exchange

---

### 🥉 #3 - OCR It
**Repo:** [`thiagotigaz/ocr-it`](https://github.com/thiagotigaz/ocr-it)  
**Language:** JavaScript  
**Why it stands out:** A browser extension for paginated documents whose text cannot be selected. Draw a capture region once, then collect the same area on subsequent pages into a transcript. Tesseract runs locally, and the documentation covers automatic page turning, duplicate detection, and export, making it useful for scanned books and slide viewers.

**Highlights:**

- A reusable screen region with keyboard capture
- Bundled Tesseract for local OCR
- Manual captures or automatic page-turning runs
- Editable page results and ordered text export

## 🔖 Honorable Mentions

### NativePDF Structurer
**Repo:** [`crunz-ai/nativePDF-structurer`](https://github.com/crunz-ai/nativePDF-structurer)  
**Language:** Python  
**Why it stands out:** Reconstructs the structure of digitally generated technical PDFs from their existing text, image objects, and vector geometry. Markdown, table CSVs, and provenance records support document workflows without OCR. It does not target scanned PDFs or semantic image understanding; its PyMuPDF dependency has separate licensing terms.

---

### Queqiao
**Repo:** [`bojieli/queqiao`](https://github.com/bojieli/queqiao)  
**Language:** Go  
**Why it stands out:** A self-hosted transport for difficult links where you control the client and gateway. Shared path measurements, forward-error correction, retransmission, and pacing address loss and latency across multiple flows. The documentation describes deployment profiles and limitations rather than treating every network as the same problem.
