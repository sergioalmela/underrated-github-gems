## 🏆 Top 3 Picks

### 🥇 #1 - network-doctor
**Repo:** [`heymaikol/network-doctor`](https://github.com/heymaikol/network-doctor)  
**Language:** Go  
**Why it stands out:** A terminal interface that explains where connectivity breaks instead of leaving users to compare unrelated command output. It models DNS, TCP, TLS, and HTTP checks as dependent probes, with an independent direct-egress branch. The June snapshot targets Linux and IPv4; its drill-down tools and report export turn a diagnosis into something a teammate can inspect.

**Highlights:**

- Separate direct-egress, DNS, and application-protocol paths
- Pass, fail, skipped, and not-applicable probe states
- Contextual ping, dig, curl, traceroute, and related tools
- Sanitized Markdown reports and bounded probe timeouts

---

### 🥈 #2 - Conduit
**Repo:** [`gwitko/Conduit`](https://github.com/gwitko/Conduit)  
**Language:** Dart  
**Why it stands out:** A mobile terminal workspace for reaching your own machines without a separate application account. SSH and Mosh sessions share a tabbed interface, with a key row for commands a phone keyboard makes awkward. SFTP, tmux integration, and explicit host-key management make it useful beyond a basic remote shell.

**Highlights:**

- SSH and Mosh sessions with saved host profiles
- SFTP browsing and transfers
- tmux helpers and configurable on-screen keys
- Android and iOS hardware-security-key authentication

---

### 🥉 #3 - aws-blocks
**Repo:** [`aws-devtools-labs/aws-blocks`](https://github.com/aws-devtools-labs/aws-blocks)  
**Language:** TypeScript  
**Why it stands out:** An AWS backend toolkit that packages runtime code, local behavior, and infrastructure in reusable blocks. A storage block can use a local implementation during development and define its AWS resources at deployment. The project is in preview, with examples that show how the same backend definition serves web and generated native clients.

**Highlights:**

- Storage, authentication, background-job, and other backend blocks
- Local development without an AWS account
- CDK and CloudFormation infrastructure generation
- TypeScript APIs with Swift, Kotlin, and Dart client tooling

## 🔖 Honorable Mentions

### kiac
**Repo:** [`saiyam1814/kiac`](https://github.com/saiyam1814/kiac)  
**Language:** Go  
**Why it stands out:** Runs local Kubernetes nodes as separate lightweight VMs through Apple's container runtime. Included metrics, storage, and LoadBalancer components make multi-node experiments more convenient. It targets Apple Silicon; the documented multi-node setup requires macOS 26 or later.

---

### mcpsnoop
**Repo:** [`kerlenton/mcpsnoop`](https://github.com/kerlenton/mcpsnoop)  
**Language:** Go  
**Why it stands out:** A proxy that captures the actual MCP traffic between a client and its server. Its terminal UI exposes requests, responses, negotiated capabilities, and pending calls, while replay gives server authors a shorter debugging loop than reconstructing a session from logs.
