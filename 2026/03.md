## 🏆 Top 3 Picks

### 🥇 #1 - gpdf
**Repo:** [`gpdf-dev/gpdf`](https://github.com/gpdf-dev/gpdf)  
**Language:** Go  
**Why it stands out:** Generating invoices or reports often means adding a browser renderer to a backend. gpdf offers a Go library with document and template layers, a grid layout, embedded fonts, and tables. Its examples cover practical documents as well as lower-level PDF operations, making it a useful building block for services that need printable output.

**Highlights:**

- Go standard library only, with no external dependencies
- Declarative layouts with a 12-column grid and reusable templates
- TrueType font embedding and CJK text support
- QR codes, barcodes, headers, footers, and page numbering

---

### 🥈 #2 - ember
**Repo:** [`alexandre-daubois/ember`](https://github.com/alexandre-daubois/ember)  
**Language:** Go  
**Why it stands out:** Caddy exposes useful metrics, but a quick traffic check should not require setting up a monitoring stack. Ember turns the admin API and metrics endpoint into a terminal dashboard with per-host traffic and latency. Its FrankenPHP integration adds worker and thread details, while JSON output makes the same information useful in scripts.

**Highlights:**

- Per-host request rates, status codes, and latency percentiles
- FrankenPHP thread, worker, and queue visibility
- JSON snapshots and deployment comparison commands
- Documented installation through Go, Homebrew, or Docker

---

### 🥉 #3 - etiket
**Repo:** [`productdevbook/etiket`](https://github.com/productdevbook/etiket)  
**Language:** TypeScript  
**Why it stands out:** A TypeScript barcode library that pays attention to the details beyond drawing black bars: validation, output formats, small imports, and scanner verification. It supports familiar retail barcodes alongside QR and other two-dimensional codes. The documentation distinguishes verified encoders from experimental ones, which helps developers choose formats with evidence behind them.

**Highlights:**

- SVG and PNG output with a command-line interface
- Separate imports for tree shaking
- QR, Data Matrix, PDF417, and common retail barcode formats
- Documented round-trip checks and experimental-format boundaries

## 🔖 Honorable Mentions

### frames-cli
**Repo:** [`viticci/frames-cli`](https://github.com/viticci/frames-cli)  
**Language:** Python  
**Why it stands out:** A practical command-line tool for placing Apple device screenshots inside product bezels. Device detection, color selection, and batch merging make it useful for release notes and app presentations. Setup requires Python, Pillow, and a separately downloaded Apple Frames asset pack.

---

### Bookends
**Repo:** [`AndyHazz/bookends.koplugin`](https://github.com/AndyHazz/bookends.koplugin)  
**Language:** Lua  
**Why it stands out:** A KOReader plugin that puts book metadata, reading progress, clocks, and device information around the reading screen. Per-line styling and reusable presets let readers build their own overlays, with a token picker that makes customization approachable.
