## 🏆 Top 3 Picks

### 🥇 #1 - SkySend
**Repo:** [`Skyfay/SkySend`](https://github.com/Skyfay/SkySend)  
**Language:** TypeScript  
**Why it stands out:** A self-hostable service for sharing files and notes without creating accounts. Its documented design encrypts content in the browser and places the decryption key in the link fragment. Expiration, download limits, and Docker deployment make the sharing workflow practical for personal servers and small teams.

**Highlights:**

- Browser-side AES-256-GCM encryption
- File uploads and encrypted text, Markdown, or code notes
- Configurable expiration, download limits, and passwords
- Docker deployment with optional S3-compatible storage

---

### 🥈 #2 - dexter
**Repo:** [`remoteoss/dexter`](https://github.com/remoteoss/dexter)  
**Language:** Go  
**Why it stands out:** An Elixir language server written in Go that indexes source directly instead of waiting for a project to compile. That makes navigation useful even when a checkout is broken or spans multiple applications. Its documentation covers several editors and explains how aliases, imports, delegates, and local variables are resolved.

**Highlights:**

- Definitions, references, hover documentation, and completion
- Source parsing without a successful Elixir build
- Umbrella and monorepo indexing
- Rename, signature help, and format-on-save support

---

### 🥉 #3 - frax
**Repo:** [`StanfordASL/frax`](https://github.com/StanfordASL/frax)  
**Language:** Python  
**Why it stands out:** Robot control experiments often need both familiar Python code and derivatives of kinematics or dynamics. frax brings those calculations into JAX, so controllers can use compilation, batching, and automatic differentiation. The repository includes interactive controller examples and explains its modeling constraints; the API is still under beta development.

**Highlights:**

- Robot kinematics and dynamics implemented in Python with JAX
- JIT compilation and automatic differentiation
- Examples for inverse kinematics and operational-space control
- Built-in Franka Panda and Unitree G1 models

## 🔖 Honorable Mentions

### cargo-crap
**Repo:** [`minikin/cargo-crap`](https://github.com/minikin/cargo-crap)  
**Language:** Rust  
**Why it stands out:** Combines function complexity with LCOV test coverage to identify risky Rust code. Its report formats, thresholds, workspace support, and baseline comparisons make it useful for deciding where additional tests or simplification could have the greatest effect.

---

### depsguard
**Repo:** [`arnica/depsguard`](https://github.com/arnica/depsguard)  
**Language:** Rust  
**Why it stands out:** Checks package-manager configuration for supply-chain settings across npm, pnpm, Yarn, Bun, and uv. A read-only scan and interactive fixes with backups make the recommendations inspectable and reversible; it also discovers Renovate and Dependabot configuration.
