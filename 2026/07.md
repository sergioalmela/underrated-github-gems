## 🏆 Top 3 Picks

### 🥇 #1 - Yap
**Repo:** [`FrigadeHQ/yap`](https://github.com/FrigadeHQ/yap)  
**Language:** Swift  
**Why it stands out:** A small native menu-bar dictation app built around Apple's on-device speech APIs. A shortcut starts recording and another press inserts the transcript into the focused application, with history stored locally. Its narrow workflow is easy to understand, though it requires an Apple Silicon Mac running macOS 26 or later.

**Highlights:**

- On-device transcription through Apple's Speech framework
- Configurable global shortcut and live transcript preview
- Insertion into the currently focused text field
- Searchable local transcript history

---

### 🥈 #2 - pixel-art-fixer
**Repo:** [`Retro-Diffusion/pixel-art-fixer`](https://github.com/Retro-Diffusion/pixel-art-fixer)  
**Language:** Python  
**Why it stands out:** Images can resemble pixel art while having blurred edges and cells that do not line up. This project detects the implied grid and reconstructs an image at its underlying pixel resolution. Its Python and Rust implementations document the detection and reconstruction stages, making it an interesting image-processing tool as well as a practical asset-cleanup utility.

**Highlights:**

- Grid detection using multiple image-processing signals
- Support for fractional cell sizes and imperfect grids
- Separate structure reconstruction and color recovery
- Python and Rust usage examples without a required model

---

### 🥉 #3 - leaves
**Repo:** [`patonw/leaves`](https://github.com/patonw/leaves)  
**Language:** Rust  
**Why it stands out:** Brings the treemap view of graphical disk analyzers to a terminal. Files and directories appear as nested rectangles, so large consumers of disk space are visible even over a remote shell. The README explains the limits of character-sized rectangles and provides navigation and filtering options for making large trees manageable.

**Highlights:**

- Terminal treemap synchronized with a directory explorer
- Keyboard and mouse navigation with directory focus
- Ignore-file support and configurable glob filters
- Rust build instructions and prebuilt release binaries

## 🔖 Honorable Mentions

### Cobalt
**Repo:** [`BandarLabs/Cobalt`](https://github.com/BandarLabs/Cobalt)  
**Language:** Rust  
**Why it stands out:** An SDK and runtime for writing Rust applications for a Kobo e-reader, with a browser simulator for development without hardware. The July snapshot supports a specific Kobo Clara BW profile and firmware; the runtime checks device identity before accessing the display.

---

### quickinbox
**Repo:** [`DivinPrince/quickinbox`](https://github.com/DivinPrince/quickinbox)  
**Language:** TypeScript  
**Why it stands out:** A self-deployed webmail client with threads, attachments, multiple domains, and multiple users. The July snapshot names the app QuickMail and documents a Cloudflare Workers/D1/R2 deployment using Resend for incoming and outgoing email; it requires those services and a domain you control.
